# WarFrontier Roadmap

## 0.1 Alpha — Foundation

- Establish repository structure and contribution rules.
- Preserve Warzone 2100 attribution and GPL obligations.
- Import the upstream codebase with traceable history.
- Produce a clean local build on Windows.
- Replace visible product naming with WarFrontier where legally and technically appropriate.
- Document all upstream assets that require attribution or replacement.

## 0.2 Alpha — Identity

- Create the official logo, icon, splash screen, and visual language.
- Redesign the main menu and core HUD.
- Establish typography, color, audio, and accessibility guidelines.
- Introduce an original launcher and build metadata.

## 0.3 Alpha — First Frontier

- Create the first original map.
- Implement the first original faction prototype.
- Add an original base set, units, and research branch.
- Build the first playable mission: Operation First Frontier.

## 0.4 Alpha — Warfare

- Expand weapons, drones, defenses, and vehicle bodies.
- Improve AI behavior and tactical variety.
- Add weather and environmental hazards where feasible.
- Begin balance testing.

## 0.5 Alpha — Multiplayer

- Validate network synchronization.
- Add private lobbies and original multiplayer maps.
- Document server and matchmaking architecture.
- Run controlled multiplayer tests.

## 1.0 — First Public Release

- Original campaign chapter.
- Stable installer and updater.
- Complete attribution package.
- Public source release compliant with GPL requirements.
- Windows, Linux, and macOS release targets where supported.
