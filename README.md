# WarFrontier

WarFrontier is a futuristic real-time strategy game project derived from the open-source Warzone 2100 codebase.

## Vision

Build a modern RTS focused on modular vehicles, base construction, research, tactical warfare, original factions, and an evolving science-fiction campaign.

## Current status

**Version:** 0.1 Alpha — Foundation

The project is currently establishing its legal, technical, and design foundations before importing and transforming the upstream codebase.

## Initial goals

- Preserve all required upstream attribution and GPL obligations.
- Import and compile the Warzone 2100 codebase.
- Rename visible game identity to WarFrontier.
- Create an original visual identity, universe, factions, maps, missions, and assets.
- Keep the project organized for future contributors.

## Planned platforms

- Windows
- Linux
- macOS

## Development model

- `main`: stable project state
- `develop`: active integration branch
- `feature/*`: isolated features
- `release/*`: release preparation
