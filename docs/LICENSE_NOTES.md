# WarFrontier — License Notes

WarFrontier is planned as a derivative project based on the open-source Warzone 2100 codebase. This document is an operational summary, not legal advice.

## Core rule

Code copied from or derived from Warzone 2100 must remain compatible with the GNU General Public License version 2 or any later version, according to the applicable upstream notices.

## Distribution requirements

When distributing a WarFrontier executable that contains GPL-covered code, the project must also provide access to the corresponding source code and preserve required copyright and license notices.

## Attribution

- Do not remove upstream copyright notices.
- Preserve authorship and contributor history where technically possible.
- Keep a clear statement that WarFrontier is an independent derivative project.
- Maintain a record of imported files, replaced assets, and newly created original content.

## Assets

Source code and game assets may not always share identical licensing terms. Before reusing any model, texture, sound, music track, video, font, logo, campaign text, or other asset, verify the notice attached to that material.

Assets with unclear or incompatible terms should be replaced with original WarFrontier content.

## Branding

Even where upstream materials permit reuse, WarFrontier should develop an original name, logo, interface, universe, campaign, factions, maps, audio identity, and promotional material.

## Release checklist

Before publishing any build:

- include the full applicable license text;
- include upstream copyright and attribution notices;
- publish the corresponding source code;
- document build instructions;
- review third-party dependencies and asset licenses;
- identify modifications made by the WarFrontier project;
- verify that downloadable source matches the released executable.

## Upstream tracking

The import process should preserve a reference to the exact upstream Warzone 2100 commit or release used as the base. Future upstream merges should be documented in the changelog.
